Install on your phone

This is a web app, so it installs to your home screen without an app store — but the file has to be opened as a webpage in the browser, not left sitting in your downloads.

Open the downloaded file → it opens in Chrome → tap the ⋮ menu → "Add to Home screen" / "Install app".
Open the Files app → find the downloaded file → tap it once (it opens a preview, not Safari) → tap the Share icon in that preview → choose "Add to Home Screen" directly from there. If Share only shows "Open in Safari", tap that first, then use Safari's own Share icon → Add to Home Screen.

Once added, it opens full-screen with its own icon. Your data is saved on this device's browser storage only — it won't sync to iCloud or other devices, and clearing Safari's website data would erase it.
